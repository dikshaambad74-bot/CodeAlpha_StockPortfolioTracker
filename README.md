# CodeAlpha Stock Portfolio Tracker

## 📌 About

This is a simple Stock Portfolio Tracker developed using Python.

The program allows users to enter stock names and quantities and calculates the total investment value using predefined stock prices.

## ✨ Features

- Displays available stocks and their prices
- Accepts stock name from the user
- Accepts quantity of stocks
- Calculates investment for each stock
- Calculates total investment value
- Uses a predefined dictionary for stock prices

## 🛠️ Technologies Used

- Python
- Dictionary
- Loops
- Conditional Statements
- Basic Arithmetic
- User Input
